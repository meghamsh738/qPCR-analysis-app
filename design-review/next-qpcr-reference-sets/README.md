# Independent qPCR reference sets

The fictional HYP-style browser check used the same target and calibrator with separate named 18S and CYC1 sets. 18S had six eligible biological samples. CYC1 had five because one sample had no CYC1 measurement. The graph, its downloadable data and the selected workbook used the same set. Both downloaded workbooks were read back and the normalised values matched the saved results; the detailed results CSV identified both sets. A phase-1 fictional package opened at its original revision with its six saved ΔΔCq endpoints, and it re-encoded byte-for-byte.
